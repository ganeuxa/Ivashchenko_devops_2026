# Цели на семестр

1. Научиться уверенно работать с Git: ветки, merge, rebase, разрешение конфликтов, работа через pull request.
2. Упаковать своё приложение в Docker-образ и поднимать связку сервисов через Docker Compose.
3. Настроить CI/CD-пайплайн на GitHub Actions, который сам прогоняет тесты и собирает проект при каждом пуше.
