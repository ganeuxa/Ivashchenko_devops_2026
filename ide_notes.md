# Git в VS Code и в терминале

## Что удобно в VS Code

1. Diff показывается в две колонки: слева старая версия, справа новая, добавленные строки подсвечены зелёным. Читать так проще, чем вывод `git diff` в консоли.
2. В коммит можно добавить не весь файл, а только выделенные строки (Stage Selected Ranges). В терминале для этого нужен `git add -p` и ответы на вопросы по каждому куску.
3. GitLens пишет прямо в конце строки, кто и в каком коммите её менял. Ещё у него есть граф веток, по нему удобно смотреть, что куда влито.

## Что удобнее в терминале

`git rebase -i`, `git cherry-pick`, `git reflog` и вообще всё, что делается по SSH на сервере или в скрипте. Там IDE нет, есть только консоль, и команды одинаково работают на любой машине.
