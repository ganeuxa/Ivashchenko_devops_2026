# Git в VS Code vs в терминале

## Что удобно в VS Code
1. **Наглядный diff** — изменения показываются бок о бок с подсветкой добавленных/удалённых строк, не нужно читать вывод `git diff` в консоли.
2. **Индексация по кусочкам** — можно добавить в коммит не весь файл, а отдельные строки (Stage Selected Ranges) в пару кликов, без `git add -p`.
3. **GitLens / blame прямо в коде** — возле каждой строки видно, кто, когда и в каком коммите её изменил, плюс удобный граф истории веток.

## Что удобнее в терминале
- **Сложные и пакетные операции** — `git rebase -i`, `git cherry-pick`, `git reflog`, работа по SSH на сервере и скрипты автоматизации: в терминале всё это делается одной командой и работает где угодно, даже там, где нет никакой IDE.
