# Мой пет-проект

Идея: телеграм-бот для учёта личных расходов — пишешь боту «кофе 250», он сохраняет трату, а по команде /stats присылает сводку за неделю и месяц по категориям.

Стек: Python (aiogram), SQLite

Цель: научиться упаковывать приложение в Docker и настроить автоматический деплой бота на сервер через GitHub Actions.
